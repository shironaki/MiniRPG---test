## Что это за ветка

Эта ветка — **отдельный проект: «Пепел и Зерно» (v3.0)**, survival-песочница
с колонией и сюжетом. Здесь нет v1 и v2: они живут в своих ветках и
развиваются независимо, другим человеком. Ничего из старых версий сюда не
переносим и в их ветки отсюда не пушим.

* Концепция и план этапов: `docs/V3-CONCEPT.md`
* Как устроен код: `README.md`
* История работ: `docs/CHANGELOG.md`

## Жёсткие правила

| # | Правило |
|---|---------|
| 1 | **Не менять `LICENSE`** и строку `Copyright (c) 2026 shironaki`, а также поля `license` / `author` в `package.json`. |
| 2 | **Никаких зависимостей, сборщиков и `node_modules`.** Только чистые ES-модули + Canvas 2D в браузере и встроенные модули Node в инструментах. |
| 3 | **Никогда `git push --force`**, не переписывать чужую историю. |
| 4 | Не удалять и не переименовывать `.git`, `LICENSE`, `AGENTS.md`, `.github/`. |
| 5 | Не коммитить бинарные артефакты и дампы: скриншоты из `tools/screenshot.js` лежат в `.artifacts/` и игнорируются git. |
| 6 | Работать в своей ветке, в чужие ветки (v1/v2) не пушить. |

Пункты 1 и 2 проверяются автоматически в `.github/workflows/guard.yml`.

## Рабочий протокол

```
SCAN → AUDIT → FIX → VERIFY → EXTEND → COMMIT → LOG
```

1. **SCAN** — прочитать `README.md` и `docs/V3-CONCEPT.md`, осмотреть
   затрагиваемые файлы целиком.
2. **VERIFY** — `npm test` (все тесты зелёные) и `npm run check` (синтаксис).
   Графику проверять глазами: `npm run shot` рендерит кадры в `.artifacts/`
   без браузера.
3. **LOG** — дописать запись в `docs/CHANGELOG.md` сверху раздела.

## Как запустить

```bash
npm start          # дев-сервер → http://localhost:3000
npm test           # 111 тестов, без зависимостей
npm run shot       # скриншоты игры в .artifacts/ (софт-рендер, без браузера)
```
